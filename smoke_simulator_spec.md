# Smoke Simulator Application

*Draft Software Specification — Version 0.1*

---

# Overview

This application provides interactive training for forest fire lookout personnel. It simulates smoke appearing in the landscape (via panoramic landscape photographs) and challenges users to practice identifying landmarks, reading the Osborne Firefinder, and completing smoke reports. The software is designed to be publicly distributable so that fire lookouts in other regions can adapt it for their own lookout stations.

---

# 1. Lookout Selection

The application supports multiple lookout stations, each with its own panorama photographs and associated metadata. The user selects the active lookout from a combo box or equivalent drop-down widget. All photographs and training scenarios presented will correspond to the selected lookout.

Lookout metadata includes the lookout name, its location (lat/long), elevation at the base, and height of the cabin.

---

# 2. Panorama and Photograph System

## 2.1 Photograph Set

The view from a lookout station is represented by a set of photographs that together form a full 360-degree panorama. Each photograph covers approximately 20 degrees of horizontal field of view. 

## 2.2 Photo Metadata

Each photograph has associated metadata that includes:

- Azimuth of the left edge of the photograph
- Azimuth of the right edge of the photograph
- A name
- A sequence number (position in panorama)

## 2.3 Panorama Navigation

The user can navigate through the full set of photographs for the active lookout:

- Step left or right sequentially through adjacent photographs

## 2.4 Smoke Images

The application will include a variety of images of different kinds of smoke (puffy, columnar, white, black, etc.)  The images will be overlayed onto the landscape photographs to create a picture for a training scenario.

---

# 4. Smoke Metadata

Each smoke to be identified by the trainee has the following stored metadata:

- ID of photograph on which it is to be displayed
- Image coordinates of a representative point within the photograph
- Geographic name of the nearest landmark
- Agency jurisdiction
- Reporting instructions: the agency or individual to whom a smoke would be reported, or a notation that no report is required
- Azimuth to the smoke
- Distance to the smoke
- Legal description (township, range, section) of the smoke location
- classification: false, legitimate, or illegitimate
- base visible: yes or no.
- description: volume (small, medium, large), color (white, gray, black, brown), character (thin, heavy, billowing, blanket, column, puffing), drift direction (N,S,E,W)
- closeup photograph: a small photograph that shows a zoomed view of the smoke, simulating the use of binoculars to get a closer view of the smoke. Ideally the landscape photographs will be of high enough resolution that the closeup can be generated by the application. Alternately this closeup photographs must be provided with the smoke metadata.
- Future enhancement: time-lapse sequence of photos of the smoke to be shown at preset intervals to simulate the growth of the fire, or a graphic animation of the changes in the smoke.

---

# 5. Training Scenarios

A training scenario presents a simulated smoke in the landscape for the trainee to locate, identify, and report.

## 5.1 Training Modes

A scenario can operate in one of two modes:

## 5.1.1 Panorama Search Mode

In search mode the user must cycle through all panorama photographs to find the one containing the smoke.

## 5.1.2 Single Photograph Mode

In this mode a single landscape photograph is presented with a smoke visible.  The task is less challenging because the trainee knows the smoke is somewhere in this single photograph. 

## 5.2 Difficulty level

Each scenario has one of three difficulty levels (Easy, Medium, Difficult) for the level of challenge associated with locating and reporting a given smoke.  The difficulty combines three factors: how hard it is to see the smoke, how hard it is to determine if the smoke is false, legitimate, or illegitimate, and how hard it is to determine the smoke's exact position.

## 5.3 Training task

In each scenario, the application overlays an illustration of smoke rising from a predetermined point in a photograph. The user's task is to find the smoke and complete a full smoke report, providing all of the following:

- Whether it is a false, legitimate, or illegitimate smoke.  For the illegitimate smokes only, the remaining fields are necessary.  Definitions:
  False = not smoke (e.g., dust or fog)
  legitimate = authorized (e.g., prescribed burn, campground campfire)
  illegitimate = unauthorized 
- Azimuth to the smoke (via the interactive Firefinder; see Section 6)
- Distance to the smoke (via the topographic map view)
- The geographic name nearest the smoke
- Legal description of the smoke location
- Whether the base of the smoke is visible
- Description of the smoke, including shape, color, and direction of drift
- The agency jurisdiction. 
- Dispatcher to report to, or that it would not be reported.

## 5.4 Scenario Metadata

A scenario is comprised of 

- a scenario ID.
- a smoke image and associated metadata (including a photograph ID)
- a difficulty level (easy, medium, difficult)

# 6. Interactive Firefinder

The application simulates the Osborne Firefinder to allow users to determine the azimuth of an object in a photograph. 

## 6.1 Azimuth Indicator

Below each photograph, the application displays a section of the fire finder base plate derived from the left- and right-edge azimuth values stored in the metadata. This display shows evenly spaced azimuth graduations marked for the azimuth range covered by the photograph.

## 6.2 Firefinder front sight

- A graphic overlay on the display resembling the forward sight of the fire finder can be turned on and off by the user.  A set of crosshairs is displayed and can be repositioned by the user via mouse movement or key presses. The user slides the crosshairs left or right until the crosshairs are aligned with the target in the photograph.
- In sync with the crosshairs, a sighting arrow and minutes scale representing the vernier plate on the rotating sight ring of the Osborne Firefinder moves left and right.
- Once the user has positioned the crosshairs, they read the azimuth value (degrees) from the position of the sighting arrow above the index marks on the base plate, and determine the minutes using the vernier plate. 

---

# 7. Topographic Map View

The application includes an optional topographic map view to assist with landmark identification and distance estimation. When the user has entered an azimuth, the application can shift to a map view centered on the lookout, showing a bearing line along the user's chosen azimuth. The map will encompass a circle of about 25 miles in radius.

Within this view, the user can:

- Scroll or zoom to locate the smoke location
- Read the geographic name of landmarks from the map
- Use an on-screen scale (similar to the ruler on the Firefinder) to estimate distance

Implementation note: The application will use LeafletJS or similar mapping service with maps from OpenTopoMap or USGS.  One approach is to show the user a high-level map like the base map of the fire finder (circular), and let them select an area to zoom in.

# 9. Metadata Management

## 9.1 Data Format

All photograph, smoke, and scenario metadata is stored in a format that can be readily read and updated by administrators without specialized software. The format should be human-readable and straightforward to edit.

## 9.2 Administrator Panel (Future enhancement)

The application includes an administrator panel with a form-based interface for managing metadata. Potential uses include entering or modifying metadata for lookouts, photographs, smokes, and scenarios.

## 9.3 Portability

The application is intended to be publicly available so that personnel in other fire districts can adapt it to their own lookout stations by substituting their own photographs and metadata. The metadata format and administrator panel are designed with this goal in mind.

# 10. Data Summary

## 10.1 Input Data

- Landscape photographs (image files, one per ~20-degree sector)
- Smoke image files
- Per-photograph metadata
- Per-smoke metadata
- Per-scenario metadata

## 10.2 User Inputs (during training)

- Selected lookout station
- Selected training mode
- Selected difficulty level
- Panorama navigation direction or index selection
- Challenge answers: geographic name, jurisdiction, reporting party, azimuth (via Firefinder interaction), distance, legal description, smoke visibility, smoke classification, smoke description

## 10.3 Outputs

- Photograph display smoke overlay or illustration
- Closeup photograph
- Azimuth indicator bar with index marks and minutes scale
- Interactive Firefinder display
- Topographic map view (optional, triggered by user)
- Evaluation feedback for each response field
